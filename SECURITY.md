# Security Policy 🛡️

Argus Audit takes the security and integrity of our auditing engine seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Argus Audit (e.g., potential bypass of the PTY interceptor, hash chain collision, secret leak, or remote escalation):

1. **Do NOT open a public GitHub issue.**
2. Please send a detailed report via email to `security@entropyparadox.com`.
3. Include reproducible steps, environment details (OS, Rust version), and potential impact.
4. We will acknowledge receipt within 48 hours and provide a fix timeline before coordinated public disclosure.
